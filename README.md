# Site personnel — Lounès Aït Karrou

Site statique à deux fichiers, prêt pour GitHub Pages.

## Fichiers

- `index.html` — tout le contenu et la structure de la page
- `style.css` — toute la mise en forme (couleurs, typographie, mise en page)

## À personnaliser avant publication

1. **Email de contact** — dans `index.html`, remplace `lounes.example@example.com` par ta vraie adresse (les deux occurrences dans `mailto:` et dans le texte affiché).
2. **Liens CV / Google Scholar** — dans la section `#contact`, les liens `href="#"` sont des placeholders. Remplace-les par de vrais liens (ou héberge ton CV en PDF dans le dépôt et pointe vers `cv.pdf`).
3. **Contenu des papiers** — les résumés dans `#research` sont volontairement généraux ; ajuste-les si tu veux qu'ils reflètent plus précisément l'état actuel de tes travaux.
4. **Titre de la page et meta description** — dans `<head>`, adapte si besoin.

## Publier avec GitHub Pages

Voir les instructions détaillées données dans la conversation. En résumé :
1. Crée un dépôt GitHub (idéalement nommé `ton-utilisateur.github.io` pour un site principal).
2. Ajoute `index.html` et `style.css` à la racine du dépôt.
3. Dans Settings → Pages, choisis la branche `main` et le dossier `/root`.
4. Le site est en ligne après 1–2 minutes à l'URL indiquée.
